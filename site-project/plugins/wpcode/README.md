# کد سفارشی

پلاگین همراه نگار، با همان ایدهٔ [WPCode](https://wpcode.com) در وردپرس: به‌جای ویرایش قالب، قطعهٔ کد را از پنل اضافه می‌کنید و مشخص می‌کنید کجا اجرا شود.

## چه چیزی را پشتیبانی می‌کند

| نوع | کاربرد |
| --- | --- |
| HTML | متاتگ، بنر، مارک‌آپ دلخواه |
| CSS | استایل سراسری یا مخصوص چند صفحه |
| JavaScript | آنالیتیکس، ویجت، اسکریپت سفارشی |
| JSON-LD | دادهٔ ساخت‌یافته برای موتور جست‌وجو |

## جای درج

- **سر صفحه** — داخل `<head>`
- **ابتدای بدنه** — درست بعد از باز شدن `<body>`
- **انتهای بدنه** — پیش از بسته‌شدن `<body>`
- **پاورقی** — پایین محتوای سایت، قبل از فوتر سیستمی

## محدوده

- **همهٔ صفحه‌ها**
- **صفحهٔ خاص** — نامک‌ها را با ویرگول جدا کنید: `about, contact`

اولویت بالاتر زودتر چاپ می‌شود. قطعهٔ غیرفعال ذخیره می‌ماند ولی تزریق نمی‌شود.

اگر خود پلاگین را از صفحهٔ پلاگین‌ها خاموش کنید، هیچ قطعه‌ای inject نمی‌شود.

## شورت‌کد

در متن مقاله یا قطعهٔ HTML صفحه‌ساز:

```
[snippet id="RECORD_ID"]
```

شناسه را از فهرست قطعه‌ها کپی کنید. فقط قطعه‌های فعال جایگزین می‌شوند.

## امنیت

این پلاگین کد را همان‌طور که مدیر نوشته اجرا می‌کند. فقط به کسی نقش مدیر یا ویرایشگر بدهید که به او اعتماد دارید. نویسندهٔ مقاله به این صفحه دسترسی ندارد.
