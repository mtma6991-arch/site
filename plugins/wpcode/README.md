# کد سفارشی (wpcode)

افزونهٔ همراه نگار، مشابه [WPCode](https://wordpress.org/plugins/insert-headers-and-footers/) در وردپرس.

از پنل: **افزونه‌ها ← اسنیپت‌ها** (`/master/plugins/wpcode`)

## چه کار می‌کند

- HTML در هدر، ابتدای بدنه یا فوتر
- CSS سراسری
- JavaScript در هدر یا فوتر
- شورت‌کد `[[snippet:شناسه]]` داخل متن صفحه و مقاله
- محدود کردن اجرا به نامک چند صفحه
- اولویت و خاموش/روشن

اگر افزونه را خاموش کنید، کدها در پایگاه می‌مانند ولی دیگر در سایت تزریق نمی‌شوند.

این افزونه کد سمت سرور اجرا نمی‌کند. برای منطق Go راهنمای ساخت افزونه را ببینید.
