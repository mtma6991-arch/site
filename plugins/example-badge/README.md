# نشان نمونه

پلاگین آموزشی. بعد از نصب در صفحه‌ساز، گروه «افزونه»، قطعهٔ «نشان» را می‌بینید.

فایل‌ها:

- `plugin.json` شناسنامه
- `blocks.json` قطعهٔ صفحه‌ساز
- `admin.json` فرم تنظیمات پنل
- `assets/badge.css` استایل عمومی وقتی پلاگین روشن است

راهنمای ساخت پلاگین: [docs/plugin-development.md](../../docs/plugin-development.md)
